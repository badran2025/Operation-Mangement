# Style catalog — 84 real-world DESIGN.md files

Each folder in `design-md/<name>/DESIGN.md` is a full design-system analysis (tokens in YAML front matter + prose rules).
Source: VoltAgent/awesome-design-md (MIT, see `design-md/LICENSE-VoltAgent-MIT.txt`). These are *independent analyses*, not official brand guides —
use them as a **visual direction**, never to impersonate the brand (no logos, names, product copy, or trademarked fonts).

`canvas` = page background, `primary` = main action color, both read from the file.
