# إدارة التشغيل — كلين

موقع إداري لإدارة تشغيل فروع كلين: الفروع، العمال، الدوام، الإجازات، السكن، المستندات، والصيانة.

- **الموقع:** https://kleen-operations.netlify.app
- **الاستضافة:** Netlify (مربوط بـ GitHub — أي push بيتنشر لوحده)
- **قاعدة البيانات وتسجيل الدخول:** Supabase (PostgreSQL) — مشروع `kleen-operations`

## التصميم
- **Fresh Fold** — مواصفاته كاملة في [`DESIGN.md`](DESIGN.md) (ألوان، خطوط، مقاسات، مكونات).
- **لغتين:** إنجليزي (افتراضي) وعربي (من اليمين للشمال) — النصوص كلها في `src/lib/i18n/dictionaries.ts`.
- **وضع فاتح (افتراضي) وداكن.**
- **الخطوط:** Work Sans للإنجليزي و Firjar للعربي (الاتنين OFL) في `src/app/fonts/`.
- **المكونات:** shadcn/ui (`src/components/ui/`) — والشعارات في `public/brand/`.

## اللي جاهز
- تسجيل دخول + أدوار: مدير التشغيل (أدمن)، مشرف فرع، مدير صيانة، فني
- الصلاحيات متطبقة جوه قاعدة البيانات (Row Level Security) — المشرف يشوف فروعه بس
- الفروع متقسمة بالمدن، وعلى كل فرع عدد العمال والشغالين والإجازات والبيانات الناقصة
- ملف العامل: البيانات، الدوام (بما فيه الدوام المقسوم)، الإجازة الأسبوعية، النقل وتغيير الوظيفة بسجل، المستندات بتواريخ الانتهاء
- صفحة المستندات اللي قربت تنتهي، السكن، المستخدمين والصلاحيات
- سجل تعديلات لكل حاجة (audit log)
- **الصيانة:** فتح بلاغ (بصور/فيديو)، تحويل لفني (مستخدم أو فني خارجي)، أولوية وموعد حل (SLA)، سجل متابعة،
  تذكير واتساب، "الفرع متوقف" بيتسجل كتوقف لحد ما البلاغ يتحل، المشرف يأكد الإصلاح ويقفل البلاغ
- 104 بلاغ قديم منقولين من Airtable

## الجاي
- تذكيرات تلقائية للبلاغات المتأخرة (إيميل)، الباك أب الليلي على Google Drive، الديزل، تقارير الصيانة

## التشغيل محلياً
```bash
cp .env.example .env.local
npm install
npm run dev
```
تعديلات قاعدة البيانات في `supabase/migrations/` (بتتطبق بالترتيب).

## متغيرات البيئة (Netlify)
| المتغير | ملاحظات |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | عام |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | عام (البيانات محمية بالصلاحيات) |
| `SUPABASE_SECRET_KEY` | **سري** — لإضافة المستخدمين فقط |
