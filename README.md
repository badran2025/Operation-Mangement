# إدارة التشغيل

موقع إداري لإدارة التشغيل: الفروع، العمال، مواعيد الدوام، السكن، والإجازات الأسبوعية.

## المرحلة 1 (جاهزة)
- **الفروع**: إضافة / تعديل / حذف، وكل كارت فرع بيظهر عليه عدد العمال وعدد اللي في إجازة النهارده.
- **العمال** جوه كل فرع: الاسم، الرقم الوظيفي، الوظيفة، الجوال، مواعيد الدوام، الإجازة الأسبوعية (يوم أو أكتر)، السكن. نقل عامل لفرع تاني من شاشة التعديل.
- **السكن**: قائمة السكنات وعدد العمال في كل سكن وتوزيعهم على الفروع.

## الجاي
- المرحلة 2: تسجيل دخول وصلاحيات (مدير تشغيل / مشرف فرع / مدير صيانة).
- المرحلة 3: قسم الصيانة (بلاغات من المشرفين ← متابعة مدير الصيانة ← حالة البلاغ).

## التشغيل محلياً
```bash
npm install
npx prisma migrate dev   # ينشئ قاعدة البيانات
npm run seed             # (اختياري) بيانات تجريبية
npm run dev
```
التقنيات: Next.js + Prisma + Tailwind. قاعدة البيانات SQLite محلياً، وعند النشر بتتغير لـ PostgreSQL.
